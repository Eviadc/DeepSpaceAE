# 运行素材

119张运行PNG及中英本地化，清单由scripts/package-game.py显式维护。普通构建直接使用已提交素材。
核心48×48，主要设备32×32，独立总线16×16，硬盘/虚影32×16，扳手16×48，开局徽章19×19，研究员半身像288×211。
完整AE2来源见../ae2-source/sources.json；抽屉来源见../drawers-source/sources.json。署名及不同许可见../THIRD-PARTY-NOTICES.md。
素材重建需Python与Pillow12.3.0，执行scripts/generate-game-assets.py；--check检查确定性输出。原版游戏素材仅作本地风格参考，不在仓库或模组中分发。
