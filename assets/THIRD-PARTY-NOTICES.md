# Steve NPC portrait

steve-portrait.png is a separately generated Steve-inspired character depiction,
created with the built-in image_gen tool for DeepSpaceAE on 2026-11-01 and resized
with its alpha preserved. It uses no copied game/Minecraft texture files and is
not an AE2-derived image. The AE2 license/attribution above does not apply to it;
no public-domain claim is made for the Minecraft character. Original output and
full prompt: assets/steve-source/README.md in the source repository, also included
as steve-artwork-source.md in the mod package.
