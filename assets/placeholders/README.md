# 原创占位素材

四种 64×64 SVG：核心（青）、管线（橙）、存储总线（绿）、终端（紫）。本项目原创的简单几何图标，不使用游戏贴图。此目录的 SVG 图标可按 CC0-1.0 使用；此说明不改变仓库其他文件的授权。

`parts.json` 只描述原型标识、显示名、图标与设备频道成本，不是游戏物品注册文件。64×64 是设计画布，不是主物品栏占格。游戏测试版使用 `assets/game/Textures/Items` 中从它们转换的 16×16 PNG；不直接把 SVG 当作 Unity Sprite 加载。实际游戏显示仍待本地验证。

Core 不依赖素材格式。SVG 复制到测试宿主输出，仅用于离线审查与报告；CLI 用文字标识设备。游戏端使用真实 API 注册自有物品与 PNG，静态核验与运行待测状态见 docs/api-verification.md。
