# 原创占位素材

四种 64×64 SVG：核心（青）、管线（橙）、存储总线（绿）、终端（紫）。本项目原创的简单几何图标，不使用游戏贴图。此目录的 SVG 图标可按 CC0-1.0 使用；此说明不改变仓库其他文件的授权。

`parts.json` 只描述原型标识、显示名、图标与设备频道成本，不是游戏物品注册文件。64×64 是设计画布，不是主物品栏占格。SVG 尚未转换为特定游戏版本支持的纹理或 Unity Sprite；不能声称游戏已加载这些素材。

Core 不依赖素材格式。素材复制到测试宿主输出，仅用于审查和验证目录；CLI 用文字标识设备。实际游戏贴图导入、精灵图注册、物品 ID、占格与旋转仍须真实 API 核验。
