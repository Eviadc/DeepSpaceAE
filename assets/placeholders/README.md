# 原创占位素材

七种 64×64 SVG：核心（青）、管线（橙）、存储总线（绿）、终端（紫）、驱动器（灰绿）、输入与输出总线。本项目原创的简单几何图标，不使用游戏贴图。此目录的 SVG 图标可按 CC0-1.0 使用；此说明不改变仓库其他文件的授权。

`parts.json` 只描述原型标识、显示名、图标与设备频道成本，不是游戏物品注册文件。64×64 是设计画布，不是主物品栏占格。实际模组使用 `assets/game/Textures/Items` 中单独授权的 AE2 衍生 PNG，不由这些 SVG 转换；SVG 不进入模组安装包。

Core 不依赖素材格式。SVG 复制到测试宿主输出，仅用于离线审查与报告；CLI 用文字标识设备。游戏端使用真实 API 注册自有物品与 PNG，静态核验与运行待测状态见 docs/api-verification.md。
