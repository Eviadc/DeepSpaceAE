# 石英扳手素材来源

wrench-generated.png为AI辅助重绘的透明源稿，以AE2 certus_quartz_wrench为身份参考，结合本游戏工具的轮廓、配色和比例。
成品保留浅蓝石英材质、水平对称且朝上的开口及实心柄。原版工具仅作风格参考，其像素不在项目中分发。
generate-game-assets.py的quartz_wrench函数将完整源稿等比缩至16×48，使用透明阈值128与七色调色板；不切片拉长。
源稿及衍生图采用CC BY-NC-SA 3.0，AE2来源与署名见assets/THIRD-PARTY-NOTICES.md和assets/ae2-source/sources.json。
