# 独立运行时测试宿主

该插件仅用于新建独立测试存档，不属于正式模组包或默认解决方案。它引用实际游戏和已安装DeepSpaceAE，调用原生UI、库存、液体及保存读取路径，不复制生产实现。

`scripts/runtime-pilot.ps1 -GameDir '<游戏目录>'` 构建并部署测试宿主，创建本地运行配置和结果目录。仅在明确需要运行时再使用启动选项；先正常退出游戏。
首次加载须在原生模组菜单审核files和reflection-external能力；不修改信任设置或绕过扫描。
已有存档和索引备份、run.json、日志及结果均保存在被忽略目录，不上传或随包分发。

耗电用例只适用于开启测试耗电选项的环境。夹具调用不覆盖真实硬件鼠标命中、所有特殊物品或其他模组交互；成功范围按实际结果逐项记录。
