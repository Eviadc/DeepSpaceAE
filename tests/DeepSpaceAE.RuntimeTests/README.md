# 独立真实运行时试验插件

只用于用户明确授权的新测试存档。独立于正式模组安装包、默认解决方案和现代 .NET 模型测试，直接引用本机 Rev6 游戏 DLL 编译；不分发游戏引用或测试存档。它通过窄范围反射调用**实际安装的** DeepSpaceAE，不复制生产逻辑，也没有对正式模组加入测试入口。

## 执行

退出游戏后在仓库运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/runtime-pilot.ps1 -Launch
```

脚本构建测试 DLL，将它及显式清单复制到 `Mods/DeepSpaceAE.RuntimeTests`，在仓库 `artifacts/runtime-tests` 中创建唯一结果目录，备份已有主存档与索引，并写入一次性 `run.json`。备份不进入 Git。首次需要用户在游戏模组管理中启用该插件并确认它声明的 `files` / `reflection-external` 权限；不修改游戏信任配置或绕过原生扫描。如果提示重启，正常退出后重新启动游戏即可，未消费的 arm 文件仍在。

修改插件且已有 arm 文件时，用 `-UpdateOnly -Launch` 只更新测试 DLL/清单，不能重新创建一次性配置。此操作要求游戏已关闭。

插件启用后先将 arm 文件改名为已领取记录，再使用主菜单正常开始游戏所用的 `InventoryScene` 场景入口进入专属开局，跳过不在测试范围内的菜单过渡动画。原版负责分配空闲存档槽。每项写入前同时校验场景身份、已启动的新开局标记、新槽 ID 及启动前槽列表；不允许在普通存档运行。没有 arm 文件时不自动开始测试。崩溃或失败不自动重放、回滚或删除物品；成功后保存新测试槽并退出，失败时保留游戏现场。

## 首轮八个用例

| ID | 实际检查 | 明确边界 |
| --- | --- | --- |
| PILOT-01 | 原生工厂创建核心、驱动器、接收器、终端和大小盘；真实占格 | 不证明全部组件动画正确 |
| PILOT-02 | 六个盘槽、三个电源槽，拒收普通卷纸，真实盘入槽 | 不模拟鼠标落点 |
| PILOT-03 | 原生主栏占格形成三叶子网络，3 频道、4 kJ | 不注入模型边或缓存网络状态 |
| PILOT-04 | 原生 3/2/1 kJ 电池共用，锁两块、闲置一块，预留不提前扣电 | 不执行夜间结算，不证明跨日账单 |
| PILOT-05 | 按原版卷纸实际面积填小盘，越界拒收留源 | 不改物品形状/堆叠回调，不穷举全部形状 |
| PILOT-06 | 建立真实终端 UI，原生存入转至第二块盘、同实例取出、目录数量 | 真实 Adapter 路径，但没有双击/拖拽/框选输入 |
| PILOT-07 | 原生移动终端断线/重连，盘中实例不变 | 不验证屏幕上的鼠标命中或动画时序 |
| PILOT-08 | 原版 SaveGame 写入新测试槽，文件存在且非空 | 保存不等于保存后重载成功 |

报告逐项写入 `result.json`，记录 PASS/FAIL、耗时、错误、游戏槽及版本上下文。加载/信任阻断单独记录为启动失败，不能当作八项执行结果。失效后续项保留未执行，不补填 PASS。

## Token 记录

`scripts/measure-runtime-usage.py` 只读取当前聊天 rollout 的 `token_count` 元数据，与任务前的累计计数做差，不导出聊天内容。基线及原始明细留在忽略的 artifacts 中。输入包括缓存输入，输出包括推理，不能重复相加；该结果不是账单或 Codex 配额换算。统计截止到最后已记录调用，单独注明末尾报告等未计入的部分。当前长聊天会有大量重复缓存上下文，应同时看总处理量、缓存输入、非缓存输入和输出，不能直接套用短上下文假设。
