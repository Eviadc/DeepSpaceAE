# DeepSpaceAE玩家指南

适用：0.16.2-alpha，Probably Stolen 100-Rev13（0.46D），Windows x64。

## 安装

创意工坊订阅后等待下载，在游戏模组菜单审核并启用DeepSpaceAE，按提示重启。
手动安装时，将包含manifest.xml的DeepSpaceAE文件夹放入游戏安装目录的Mods。
相同ID的本地Mods副本优先于工坊订阅版。更新前退出游戏，保留自己的存档备份。

## 开始使用

1. 新建游戏选择网络工程师，或向王尔德购买AE工程师升级。
2. 在主物品栏或原版机器区／扩建机器区中放置核心、终端和驱动器。默认无需电池，无频道数量限制。终端、驱动器、物品接口、流体接口和能源接收器均可转发网络，可直接相邻串联，也可用线缆延伸或连成环。每张连通网络只允许一个核心；经设备连接两个核心会使整网冲突，移除多余核心后恢复。
3. 将存储总线拖到线缆上，让总线面朝相邻容器；双击总线部位配置筛选。总线占用的面不再向外传网，目标容器不会因此成为中继。
4. 双击终端查找物品；窗口记忆上次位置，标题栏百分比按钮循环切换100%／50%／75%界面尺寸。标签及当前顾客需求筛选已内置。相同状态物品显示总数，每次从一堆取出一件；排序菜单可选“修改时间”，最近变化的堆排在前面。
5. 双击驱动器放入硬盘。初始两个盘位，每张容量卡解锁两个，最多十个。驱动器与总线的配置面板直接显示优先级，数值越高越优先接收物品。
6. 拨打礼包电话条上的6322，预约福鲁伊克斯研究员次日来店供货。

输入总线从机器收货，机器刚产生的物品会优先入网，网络拒收或满容量时再走原版输出和后备库存。输出总线向机器送料。两种总线也可对准普通储物区双向搬运物品，支持多页储物区；仍遵守筛选、存取锁和物品所有权。
普通总线筛选默认黑名单，空黑名单允许全部；空白名单拒绝全部。抽屉基础16件，每张容量卡×4；同种物品的不同进价不妨碍合并，也不会抹掉原进价。
抽屉面板可锁定物品种类，取空后仍只接受同种物品；解锁并清空后才能换种类。锁定空抽屉时，会记住下一件放入的物品。抽屉的“溢出销毁”默认关闭；开启后，只销毁符合种类但超过容量的新投入部分。
物品接口中可开启“自动收纳购入物品”（默认关闭），成交及批发购买后自动入网，容量不足时保留原版落点。
商人每次保底小盘2个、大盘1个、标签卡1张，另外按概率少量追加；线缆和容量卡数量已降低，给后列商品留出货台空间，不补满货台。
开局和升级礼包各赠送两个无线连接器，不赠送电池。村民商人的连接器有35%概率出现，每次2个或4个；货台空间不足时只保留完整的一对。
流体使用原版选中与目标交互，接口缓冲20升。完整规则见源码仓库的功能规格。

## 无线连接与总线形态

无线连接器占2×2格。像原生料斗一样，单击选中一端，再点击另一端配对；重新配对会解除两端的旧连接，双击可查看另一端或解除配对。连接器接入所在物品栏中相邻的 AE 设备和线缆，跨容器传网，不要求窗口打开。配对两端必须有效拥有；两端连到两个核心时会整网冲突。主物品栏、原版机器区／扩建机器区及放有连接器的物品栏参与组网，存放在其他箱中的备用组件保持离线。

接口及存储／输入／输出总线可在右键菜单选“切换”改变物品／流体形态，也可使用配置窗口的形态按钮。配置与升级卡保留；接口有液体时先排空。商人和拾荒只提供统一接口，不再单独提供流体接口。流体存储总线读取朝向的真实液体容器；流体输入／输出总线抽取或填充朝向的容器，也可处理机器对应出／入槽中的液体容器。默认不混合不同成分，可在总线配置关闭严格匹配。

放置、吸收总线只处理物品。默认作用于总线正对的一格；已有物品时不继续放置或堆叠。空白名单不放置，空黑名单可放置所有合格物品。作用范围可改为“整个所在物品栏”，仍使用相同的黑白名单、标签和精确筛选，不递归处理子容器。整栏吸收保留 AE 设备、硬盘、卡片、扳手等组件及原生料斗。两种总线遵守原生容量、所有权和锁定规则，并与输入／输出总线一样按料斗时序运行，也可按“立即运行”。
