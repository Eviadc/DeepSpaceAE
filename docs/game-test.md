# DeepSpaceAE 0.3.1-alpha · 安装和验收

编译核验基线：100-REV3 / Windows x64。用户已报告游戏升级至 REV5，但云端尚未收到对应真实程序集；本包没有宣称 REV5 兼容。0.2 多数功能由用户确认可用，0.3 原生 UI/拖放重构仍需本地验收。先使用独立测试档并保留备份。

0.3.0 有一个确定的加载阻断：Harmony 目标 GameItem.Destroy 是抽象方法。请改用 0.3.1；不能仅以旧包编译成功判断已加载。F8 缺字时按 [加载诊断](load-troubleshooting.md) 读取 Player.log，省去在控制台中找异常。

## 安装

退出游戏，将 ZIP 内整个 DeepSpaceAE 文件夹放进游戏安装目录 Mods，替换旧模组目录，避免混用 DLL/纹理。包内有两个自有 DLL、43 张授权 PNG、2 份本地化 CSV、manifest、安装说明、素材许可/来源、只读日志提取脚本和构建记录，没有游戏/Unity/Harmony DLL。按官方指南启用带程序集的模组；运行不需要 F8/F9 或开发参数。

禁用或卸载前先取回电池、拆下卡片并移除全部 AE 物品。未知移动/结算结果出现后停止测试，保留日志，不反复点击补偿。不承诺真实保存安全或跨容器原子事务。

## 使用

核心 3×3，其余节点 1×1。直接放在主物品栏，每个网络一个核心；总线箭头接真实容器、背面接网络，线缆自动连接。核心 32 频道、线缆 8，终端/总线各占一个。不可用时熄灭；组件均双击打开，单击保持拖拽。

双击核心进入原生机器样式的网络控制器。组件贴图展示数量，电源图标和能量条展示每晚预算。直接把真实电池拖入电池槽，满足整晚用电才接收；没有候选电池列表，也不会自动从主栏取电池。核心/线缆/总线/终端每晚分别 2/0/1/1 kJ。电池插入后锁定，夜间只扣一次，次日解锁才能拖出更换；先打开终端会预留当天预算并再次锁定。超科技电池沿用原生输出限制和无限能量语义，转换器不是电池。

双击总线：中间是九列幽灵筛选格，旁边设置包含/排除、存取模式、取出是否筛选，优先级在独立小面板中编辑。把物品拖到幽灵格会复制类型，物品仍留在原库存；点击幽灵格清除。空配置接收全部。容量卡每张 +9 格，最多 5 卡；安装标签卡后以原版类别筛选，从刚拖入物品自身的类别选择。本地化显示类别名称，不列出内部状态代码。升级卡直接拖进下方真实升级槽；用 AE 扳手作用于总线，逐张拆回主栏，满时拒绝。

双击终端：主要区域为网络物品的虚拟库存。物品按真实多格形状、旋转和翻转展示，保留原生悬停提示，同 ID 不同状态分别显示。顶部搜索/类别/排序只作用于网络库存，没有主栏候选面板。#类别搜索支持本地化名称；翻页不会搬动物品。

直接从游戏原主物品栏或其他拥有的真实库存拖入终端，按总线优先级/筛选选择实际空位。把终端物品拖到游戏原库存的真实空位即可取出，可沿用原版旋转/翻转；拖到空屏幕、满或拒收位置，或按 Esc 取消。当前只搬运整实例，不支持 Alt/Shift/滚轮拆分或强制堆叠。终端内重排仅调整显示位置，重新筛选或库存变化后按排序重排，不修改真实容器的位置。

拾荒沿用 0.2 的独立 AE 池：向可用 POI_* 组加权重 20；原版总权重通常 1000，约占 20/1020，其他模组会影响比例。池内核心/线缆/总线/终端/容量卡/标签卡/扳手权重 1/8/3/2/2/1/3。

## 本地重点复测

分别记录通过、失败、未运行及包的源码提交。

1. 控制器是否与原版机器风格一致；贴图、数量、能量条可读，电池仅经拖入安装；不足电拒收，锁定不能绕过，次日可拖出。长线缆不增加耗电。
2. 总线幽灵格拖放不移动原物，点击可清除，访问/包含/排除/取出筛选/优先级实际生效；标签只显示本地化类别，卡片变化即时更新有效槽。
3. 终端的 1×1、2×3、不规则带孔、旋转和翻转物品占格及悬停正确；同 ID 状态不同不合并；搜索、类别、排序和翻页保持实例完整。
4. 从真实库存拖入终端、终端拖出到指定空位、拖回空白、满/拒收、锁定来源、拖拽期间断线或物品变化；不得因一次释放发生两次移动。按 Alt/Shift 取部分时应拒绝而非悄悄拆分。
5. 重开窗口不搬动电池/卡片；0.2 存档升级后子库存仍完整，数量/状态不变；原未结算预算按新功耗迁移但已扣/未知结算不重扣。保存退出重载后逐一核对。
6. 原版物品拖放、机器窗口及其他模组库存没有被虚拟库存补丁接管；组件双击/单击拖拽和明暗仍正常。
