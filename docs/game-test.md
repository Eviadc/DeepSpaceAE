# DeepSpaceAE 0.2.0-alpha · 安装和验收

目标游戏：100-REV3 / Windows x64（用户报告 Steam Build 26284217）。前一版 37f61bf 的基础交互由用户确认可用；本版新增功能尚未启动真实游戏验收。先用独立测试存档并保留备份。云端模型与编译结果不能代替此处验收，不承诺跨容器原子事务。

## 安装

退出游戏，将 ZIP 中整个 DeepSpaceAE 文件夹放入游戏安装目录 Mods。替换旧版本目录，避免混用 DLL/纹理；保留原存档备份。包内应有两个自有 DLL、43 张已署名的 AE2 衍生 PNG、manifest、本文、素材许可和构建记录；没有游戏、Unity、Harmony DLL。按官方指南启用带程序集的模组并重启；不需要额外启动参数。开发工具不是运行依赖，旧 AE 测试/诊断按钮已移除。

不要在尚未移除电池、升级卡和全部 AE 物品的存档中停用模组。优先在副本中验证下述保存往返。

## 基本使用

所有网络组件只在主物品栏直接摆放时工作。核心占 3×3，其他组件占 1×1。双击打开界面，单击保持拖拽。每个网络一个核心，终端/总线各用一个频道，核心 32、每段线缆 8。线缆自动连接；总线箭头面接真实容器，背面接核心或线缆，使用游戏原生旋转/翻转调整。

未供电、核心冲突、无核心、频道不足、总线未接容器、不属于玩家或离开主栏时显示熄灭变体。熄灭并不删除已有内容。升级卡和扳手是普通道具，不是供电节点。

双击核心打开网络管理，查看设备数、频道、用电及电池状态。从主栏选择可用电池安装：必须能满足当前整个网络一晚用电。每晚核心 8、线缆 1、总线 4、终端 4 kJ；连在网络中的未使用设备也计入待机预算。普通电池按实际能量扣除；原生超科技电池沿用原版输出限制和不减能量语义；转换器不是可装电池。

电池安装或首次打开终端后锁定，全天预留预算取已启用网络的最高值。扩建超出电池能力时网络停用；拆线不减少已经承诺的预算。睡眠早期只扣一次，在下一次 StartDay 后解锁。次日可先打开核心更换电池，再使用终端；不要先打开终端，否则会再次预留当天预算。中断或扣电结果不明时保持锁定，不自动重扣。

终端显示本网络所有在线总线接入的直接库存，重复接入同一容器不重复计数，不递归暴露袋中袋。支持名称/ID 搜索、空格分词、#标签搜索、标签下拉筛选和名称/数量排序。点击网络物品取回主栏；点击下方主栏物品自动存入最高优先级的合规空位。每次操作重新检查真实归属、网络、筛选和空位；仅移动整实例，不拆分、不合并堆叠。同 ID 不同状态仍分别显示。未知原生移动结果会锁定后续操作，不补造、不回滚、不重试。

双击总线设置整数优先级（越大越先存）、双向/仅取出/仅存入、包含或排除、取出是否使用筛选。空筛选接收全部。筛选格是幽灵配置，不消耗被筛选物品；点击格后从主栏复制物品类型，或输入精确 ID。基础 18 格，每张容量卡 +9，最多 5 张、63 格。标签卡占一个升级位且限一张，改为真实游戏标签筛选，余下最多 4 张容量卡、54 格。两种筛选分别保存；卸卡后超额格停止生效，配置保留。

在主栏选择升级卡安装。使用 AE 扳手像原版钳子/螺丝刀那样选择并作用于总线，每次拆下一张实际卡片放回主栏，主栏没有完整空位时拒绝，不创建替代物品。卡片安装顺序的逆序拆卸。

拾荒通过原版 POI_* 战利品组增加一个权重 20 的 AE 池；原版权重总和通常 1000，因此无其他修改时该池约占 20/1020。池内核心/线缆/总线/终端/容量卡/标签卡/扳手权重为 1/8/3/2/2/1/3。与其他模组权重共同归一化，不保证固定几次必出；没有 POI 组时英文日志明确报不可用。原生开发物品目录仍可用于独立测试，但没有自定义生成按钮。

## 本地验收清单

分别记录通过、失败、未运行；附源码提交和相关原版日志。

1. 四类组件在主栏/袋内/未拥有/断线/多核心/无电/频道耗尽时明暗正确；四向总线及翻转、连接贴图、双击和拖拽保持正常。
2. 多个真实容器同时可见；搜索中文、ID、#标签及下拉组合；排序和翻页；同 ID 不同耐久/电量/状态不误合并；重复总线不重复计数。
3. 高优先级先存，满时尝试低优先级；拒收/满/锁定无丢失；包含/排除、读写模式、取出筛选均有效。搬动总线或物品后点击旧页面不得误搬。
4. 容量卡每张 +9，标签卡只允许一张，卡位最多 5；物品与标签模式独立保存；扳手逐张取回，主栏满时卡片仍在总线内。
5. 不足电池拒收；足够电池插入即锁；原生拖出、右键、工具、换电等入口均不能绕过锁定。扩建欠电变暗；拆线不减当天预算；睡眠只扣一次，次日解锁；重载当天/结算后存档保持状态。
6. 保存、退出、重载：电池和升级卡的真实实例/状态/数量、总线配置、夜间预算保持；旧 0.1.0 存档升级后不再显示测试说明。确认卸载准备流程没有丢失子库存。
7. 拾荒确实能出现组件/卡/扳手，重复进出场景和模组启停不增加重复权重；与其他库存/电池模组一起测试。

失败时退出当前操作，保留日志及测试档副本；不要通过反复点击补偿未知结果。报告发生在哪一步和扣电前后能量/物品位置，不需要公开上传存档或游戏 DLL。
