# DeepSpaceAE玩家指南

适用：0.15.0-alpha，Probably Stolen 100-Rev12（0.46D），Windows x64。

## 安装

创意工坊订阅后等待下载，在游戏模组菜单审核并启用DeepSpaceAE，按提示重启。
手动安装时，将包含manifest.xml的DeepSpaceAE文件夹放入游戏安装目录的Mods。
相同ID的本地Mods副本优先于工坊订阅版。更新前退出游戏，保留自己的存档备份。

## 开始使用

1. 新建游戏选择网络工程师，或向王尔德购买AE工程师升级。
2. 在主物品栏放置核心，用线缆连接终端和驱动器。默认无需电池，无频道数量限制。
3. 将存储总线拖到线缆上，让总线面朝相邻容器；双击总线部位配置筛选。
4. 双击终端查找物品；标签及当前顾客需求筛选已内置。相同状态物品显示总数，每次从一堆取出一件；排序菜单可选“修改时间”，最近变化的堆排在前面。
5. 双击驱动器放入硬盘。初始两个盘位，每张容量卡解锁两个，最多十个。
6. 拨打礼包电话条上的6322，预约福鲁伊克斯研究员次日来店供货。

输入总线从机器收货，输出总线向机器送料。抽屉基础16件，每张容量卡×4；同种物品的不同进价不妨碍合并，也不会抹掉原进价。
物品接口中可开启“自动收纳购入物品”（默认关闭），成交及批发购买后自动入网，容量不足时保留原版落点。
商人每次保底小盘2个、大盘1个、标签卡1张，另外按概率追加；不补满货台。
流体使用原版选中与目标交互，接口缓冲20升。完整规则见源码仓库的功能规格。
