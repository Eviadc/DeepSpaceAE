# 原生界面与交互

终端采用独立纯UI镜像，不借用源物品handler/middle，不将镜像加入保存图。源容器和终端可同时显示同一真实物品；所有命中包含数量文字都指向顶端真实实例。
原版双击、右键菜单、工具目标、拖拽和群组选择继续使用真实物品身份。每个显示堆叠最多选择及移动一件；滚动、筛选或重建清理旧选择。
界面为12×8滚动视口及两行工具栏，内置标签与顾客筛选。存入高亮覆盖整个接收区。总线过滤栏采用固定九列，随容量卡增行，没有滚动条。

原版CustomUI设计比例为2，整体缩放并保留输入框、下拉和勾选装饰。使用普通库存背景。电池/升级槽可用独立布局包装，不借走终端源容器的渲染。
核心、驱动器、抽屉和接口使用真实原生机器面板。线缆不提供独立UI，双击安装面打开对应总线；工具拆卸使用实际面解析及原生准入。

抽屉本地窗口显示一个代表和总数。物品表面/拖动预览上的缩略图在SetSimple之后保持20px布局，数字和图像不拦截投放。代表只在本地真实库存拖入时充当落点，终端镜像不能绕过网络权限。
液体卡文字区同样绑定真实容器，沿用原生选中/Target及TransferLiquid，不把源容器当物品从网络搬走。

库存、数量、配置及网络事件合并刷新；拖拽期间保留dirty，结束后重建可见区域。没有逐帧全目录扫描。特殊物品依赖原场景节点的行为仍需单独核验。
