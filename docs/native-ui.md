# 0.3 原生 UI 迁移

按用户对 0.2 的实际反馈重构。用户确认多数功能可用，但指出界面、取电池方式、筛选候选列表和终端主栏面板不符合预期。该反馈不代替 0.3 UI 的真实运行验收。

## 对照及实现

参考 AE2 固定提交 629d953f987f37a768fbf96551c97d3dfd07b7ee 的 screens/storage_bus.json、network_status.json、priority.json：总线中心为九列 CONFIG 幽灵格，旁侧访问/匹配控制，优先级独立编辑；控制器按组件贴图列统计；终端主要区域是库存。按用户要求迁移交互，不引入合成等本轮不适用项。

真实 100-REV3 的 MachineDnaManipulator.CreateMachineInventoryWindow、MachineHelper.PowerPanel、MachineryPanelRow、MachineryIntake、GameSlotInventory 构成原版机器界面。本版使用这些真实像素机器组件、图标、进度条、输入框皮肤和电池槽背景/音效。控制器不枚举电池候选、不点击自动安装；用户直接从原库存拖电池进槽。槽默认 1×1，与原版相同，实际装入物品时由原版调整显示。

原来的电池槽/升级槽仍挂在原先 contentWindow 的原生数据图中，节点顺序保持稳定。新机器窗口借用原生 StealPixelElement 渲染这些现有槽；关闭时归还渲染父级，不改变真实库存的 parent 或子物品归属。没有为重排 UI 给旧存档增加库存节点偏移，更不把真实卡片或电池移到临时窗口里保存。

总线使用九列幽灵筛选格；拖入只复制类型 ID，不移动物品。点击清除。标签卡模式只从被拖物品的真实公开类别中选择，不扫描主栏、物品目录或全世界生成候选物品。类别通过原版 TypeHelper.GetTypeDisplayName（Mechanic/type_*）转换，终端的类别下拉和 #类别搜索也采用本地化名称。内部状态标签不再混入展示列表；既有策略匹配仍可识别原始键。

## 虚拟库存与拖放

VirtualInventory 是真实 GameGridInventory 的显示子类，内部不接收 GameItem，childItems/children 为空。每个显示片引用现有实例，保持其原生 sprite、旋转、翻转、实际占格和原生悬停提示；数量显示在该物品边缘，不建立新实例，不合并同 ID 物品。终端只显示网络库存，游戏原本的主物品栏继续承担玩家库存，没有自建主栏候选面板。

布局按当前原生 ForwardTransform 观测归一化；Core 的线性 shelf 算法按物品形状的外框排放，保留孔洞，不做 NP 难的最优紧密装箱。空间不够时分页，超大物品扩展页面而非裁切或遗漏。页内命中使用实际占格的哈希索引；显示重排只改投影坐标。它不会写回真实容器，也不制造容量。

输入接入真实 ItemMouseDragHandler：仅在按下投影物品时把原生拖拽对象指向真实来源实例。原版负责门槛、预览、旋转/翻转和释放清理。投影中拖入/拖出时，在 EndDrag 前执行一次重新核验的整实例移动，随后清空原版目标，让原版只做预览清理，避免二次提交。对虚拟槽的 TryAcceptOnce/AcceptUnchecked 额外拒绝，禁止其他原生路径把物品放入显示层。

释放前重新读取网络、供电、总线权限/优先级、来源和目标可接收状态。放到空屏幕或拒收位置取消；只能移动整个实例，仍不拆分或强制堆叠。未知结果锁定操作，不重试其他总线，不回滚或补造。若原生移动后实例暂时无 parent，保留真实对象并阻止原版拖拽结束分支自动 Destroy（包括 GameItemElement 覆盖），便于停止测试取证；这不是存档恢复或跨容器事务保证。

## 用电修订

每晚核心 2、总线 1、终端 1 kJ，电缆 0。它们是本游戏按夜的模组计费，不宣称与 AE2 的 AE/t 数值等价。旧版未扣的 Reserved 预算仅在功耗策略迁移时重算一次；移出可观测网络的旧预算按四分之一向上取整、最少 2 迁移。DebitStarted、Settled、Fault 不改、不退款、不重放，之后的新预留继续保留本日峰值。

## 成本及验证边界

一次投影排放 O(M+A)，M 为实例数，A 为其占格总数；空间 O(M+A)。查询命中期望 O(1)。显示重排验证和更新 O(该实例占格)，跨页列表移除使用索引交换；页面读取与渲染不重新复制整个 Live 字典，也不重扫全部库存。搜索/排序改变才重排；实际库存事件会失效观测。仍然保留写入前的完整真实观测成本，不能以 UI 缓存授权取放。

源代码已用真实 REV3 引用编译，模型测试覆盖孔洞、多格、分页、大物品、重排冲突、实例保留、本地化搜索、零电缆功耗及待扣预算迁移。云端没有 Unity 运行时，无法据此确认鼠标路由、窗口比例、机器皮肤、真实保存往返已经正确。REV5 引用仍缺失，不把此包冒称为 REV5 编译验证。

原生 OnEventReset 在拖拽未结束时可能调用 EndDrag；取消分支先清除虚拟目标并标记取消，防止 Esc 意外提交。隐藏原生窗口（含 Esc）也解除目录订阅和借用槽，不在关闭后继续刷新隐藏界面。

## 0.3.2 本地反馈修订

用户报告终端物品无法选中/拖出，电池和升级槽布局错误。本轮针对实际输入与原生布局契约修订，未增加存储玩法或改变保存图索引。

- 终端投影和占格命中统一使用左上锚点/原点；按下时沿实际 ItemTile 的渲染祖先找投影，读取原生捕获的指针位置，核对显示来源，再设置真实拖拽对象及对应按键。单击只更新投影的选中格，不激活真实容器里的物品；拖拽仍经过原版门槛、重新核验和一次原生移动。命中面覆盖实际占格，并保留细微可见 alpha，避免完全透明的命中面被剔除；孔洞不成为取出入口。没有把投影片伪装为 GameItemElement。
- 删除刷新按钮，页码为静态文字。库存事件以 dirty 标记合并到下一次更新；拖拽/写入期间保留标记，结束时补刷。窗口订阅世代变化使旧回调失效，不以逐帧扫描维持 UI。释放前仍做真实观测，不用显示缓存授权写入。
- 静态核对 MachineryContainerUtils.Refresh/TryResize：它只处理 MachineryContainer/MachineryWidget，**不处理 StealPixelElement**。旧 Borrow 没有主动验证它，宽高可保持 0；Attach 也会保留库存旧窗口偏移。新 BorrowedInventoryView 实现真实 MachineryWidget，主动验证槽尺寸、把借用内容放在局部原点，关闭时归还并恢复原偏移。它不实现 GraphNodeStorage，不把真实库存加入新窗口的保存图。核心使用原版 Power/IconPanel 布局，总线的升级槽置于独立右侧面板。
- CustomUIMachineryStyle.SCALE 实际为 2。输入/下拉控件按两倍设计尺寸建立、整体缩回一半，保留正确字高、内边距和箭头，不再把原字体硬裁进小框。使用原版控件 prefab，再应用原版机器字体/外框；原版 Reskin 会替换所有 Image，因此在创建控件时保留其子图像装饰（下拉箭头、勾选符号）。此处仅对自有控件的公开 Unity UI 属性作有限反射，不查私有游戏字段、不逐帧执行。总线访问/匹配用下拉、取出筛选用复选，操作按钮只用于优先级编辑等动作；控制器组件统计是贴图和文字。
- 16 种连接图完整采样 AE2 glass cable 的 center/connection/straight 顶面和 UV。保留原素材透明孔洞，不再画纯色连接臂。12 张核心帧从 controller_lights.png 等距裁取并合成原版底图，保持同为 48×48。供电联网时调用真实 SpriteAnimationHelper.InitSpriteAnimation，每帧 500 ms（原 mcmeta 的 25 tick）；关闭/拆离/停用时移除自有动画，熄灭。复用原生动画管理器，不运行网络扫描、不动态创建纹理；不声称复现原 Minecraft 的插值着色。

当前素材白名单 55 PNG（43 基础 + 12 动画帧），含许可及固定来源哈希。字形刷屏仍按用户要求搁置；没有全局修改字体/日志开关。新命中路径、布局、动画及控件比例都需要用户在真实游戏复测；真实引用编译和元数据检查无法替代现场 UI 验收。
