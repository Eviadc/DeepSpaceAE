# 0.3 原生 UI 迁移

> 当前 0.8.0 行为以 [完整功能规格](feature-spec.md)、[用例矩阵](functional-cases.md) 为准。下文按版本保留历史实现背景，不能恢复旧终端渲染借用、独立总线或旧电源策略。

按用户对 0.2 的实际反馈重构。用户确认多数功能可用，但指出界面、取电池方式、筛选候选列表和终端主栏面板不符合预期。该反馈不代替 0.3 UI 的真实运行验收。

## 对照及实现

参考 AE2 固定提交 629d953f987f37a768fbf96551c97d3dfd07b7ee 的 screens/storage_bus.json、network_status.json、priority.json：总线中心为九列 CONFIG 幽灵格，旁侧访问/匹配控制，优先级独立编辑；控制器按组件贴图列统计；终端主要区域是库存。按用户要求迁移交互，不引入合成等本轮不适用项。

真实 100-REV3 的 MachineDnaManipulator.CreateMachineInventoryWindow、MachineHelper.PowerPanel、MachineryPanelRow、MachineryIntake、GameSlotInventory 构成原版机器界面。本版使用这些真实像素机器组件、图标、进度条、输入框皮肤和电池槽背景/音效。控制器不枚举电池候选、不点击自动安装；用户直接从原库存拖电池进槽。槽默认 1×1，与原版相同，实际装入物品时由原版调整显示。

原来的电池槽/升级槽仍挂在原先 contentWindow 的原生数据图中，节点顺序保持稳定。新机器窗口借用原生 StealPixelElement 渲染这些现有槽；关闭时归还渲染父级，不改变真实库存的 parent 或子物品归属。没有为重排 UI 给旧存档增加库存节点偏移，更不把真实卡片或电池移到临时窗口里保存。

总线使用九列幽灵筛选格；拖入只复制类型 ID，不移动物品。点击清除。标签卡模式只从被拖物品的真实公开类别中选择，不扫描主栏、物品目录或全世界生成候选物品。类别通过原版 TypeHelper.GetTypeDisplayName（Mechanic/type_*）转换，终端的类别下拉和 #类别搜索也采用本地化名称。内部状态标签不再混入展示列表；既有策略匹配仍可识别原始键。

## 虚拟库存与拖放

VirtualInventory 是真实 GameGridInventory 的显示子类，内部不接收 GameItem，childItems/children 为空。每个显示片引用现有实例，保持其原生 sprite、旋转、翻转、实际占格和原生悬停提示；数量显示在该物品边缘，不建立新实例，不合并同 ID 物品。终端只显示网络库存，游戏原本的主物品栏继续承担玩家库存，没有自建主栏候选面板。

布局按当前原生 ForwardTransform 观测归一化；Core 的线性 shelf 算法按物品形状的外框排放，保留孔洞，不做 NP 难的最优紧密装箱。空间不够时分页，超大物品扩展页面而非裁切或遗漏。页内命中使用实际占格的哈希索引；显示重排只改投影坐标。它不会写回真实容器，也不制造容量。

输入接入真实 ItemMouseDragHandler：仅在按下投影物品时把原生拖拽对象指向真实来源实例。原版负责门槛、预览、旋转/翻转和释放清理。投影中拖入/拖出时，在 EndDrag 前执行一次重新核验的整实例移动，随后清空原版目标，让原版只做预览清理，避免二次提交。对虚拟槽的 TryAcceptOnce/AcceptUnchecked 额外拒绝，禁止其他原生路径把物品放入显示层。

释放前重新读取网络、供电、总线权限/优先级、来源和目标可接收状态。放到空屏幕或拒收位置取消；只能移动整个实例，仍不拆分或强制堆叠。未知结果锁定操作，不重试其他总线，不回滚或补造。若原生移动后实例暂时无 parent，保留真实对象并阻止原版拖拽结束分支自动 Destroy（包括 GameItemElement 覆盖），便于停止测试取证；这不是存档恢复或跨容器事务保证。

## 用电修订

每晚核心 2、总线 1、终端 1 kJ，电缆 0。它们是本游戏按夜的模组计费，不宣称与 AE2 的 AE/t 数值等价。旧版未扣的 Reserved 预算仅在功耗策略迁移时重算一次；移出可观测网络的旧预算按四分之一向上取整、最少 2 迁移。DebitStarted、Settled、Fault 不改、不退款、不重放，之后的新预留继续保留本日峰值。

## 成本及验证边界

一次投影排放 O(M+A)，M 为实例数，A 为其占格总数；空间 O(M+A)。查询命中期望 O(1)。显示重排验证和更新 O(该实例占格)，跨页列表移除使用索引交换；页面读取与渲染不重新复制整个 Live 字典，也不重扫全部库存。搜索/排序改变才重排；实际库存事件会失效观测。仍然保留写入前的完整真实观测成本，不能以 UI 缓存授权取放。

源代码已用真实 REV3 引用编译，模型测试覆盖孔洞、多格、分页、大物品、重排冲突、实例保留、本地化搜索、零电缆功耗及待扣预算迁移。云端没有 Unity 运行时，无法据此确认鼠标路由、窗口比例、机器皮肤、真实保存往返已经正确。REV5 引用仍缺失，不把此包冒称为 REV5 编译验证。

原生 OnEventReset 在拖拽未结束时可能调用 EndDrag；取消分支先清除虚拟目标并标记取消，防止 Esc 意外提交。隐藏原生窗口（含 Esc）也解除目录订阅和借用槽，不在关闭后继续刷新隐藏界面。

## 0.3.2 本地反馈修订

用户报告终端物品无法选中/拖出，电池和升级槽布局错误。本轮针对实际输入与原生布局契约修订，未增加存储玩法或改变保存图索引。

- 终端投影和占格命中统一使用左上锚点/原点；按下时沿实际 ItemTile 的渲染祖先找投影，读取原生捕获的指针位置，核对显示来源，再设置真实拖拽对象及对应按键。单击只更新投影的选中格，不激活真实容器里的物品；拖拽仍经过原版门槛、重新核验和一次原生移动。命中面覆盖实际占格，并保留细微可见 alpha，避免完全透明的命中面被剔除；孔洞不成为取出入口。没有把投影片伪装为 GameItemElement。
- 删除刷新按钮，页码为静态文字。库存事件以 dirty 标记合并到下一次更新；拖拽/写入期间保留标记，结束时补刷。窗口订阅世代变化使旧回调失效，不以逐帧扫描维持 UI。释放前仍做真实观测，不用显示缓存授权写入。
- 静态核对 MachineryContainerUtils.Refresh/TryResize：它只处理 MachineryContainer/MachineryWidget，**不处理 StealPixelElement**。旧 Borrow 没有主动验证它，宽高可保持 0；Attach 也会保留库存旧窗口偏移。新 BorrowedInventoryView 实现真实 MachineryWidget，主动验证槽尺寸、把借用内容放在局部原点，关闭时归还并恢复原偏移。它不实现 GraphNodeStorage，不把真实库存加入新窗口的保存图。核心使用原版 Power/IconPanel 布局，总线的升级槽置于独立右侧面板。
- CustomUIMachineryStyle.SCALE 实际为 2。输入/下拉控件按两倍设计尺寸建立、整体缩回一半，保留正确字高、内边距和箭头，不再把原字体硬裁进小框。使用原版控件 prefab，再应用原版机器字体/外框；原版 Reskin 会替换所有 Image，因此在创建控件时保留其子图像装饰（下拉箭头、勾选符号）。此处仅对自有控件的公开 Unity UI 属性作有限反射，不查私有游戏字段、不逐帧执行。总线访问/匹配用下拉、取出筛选用复选，操作按钮只用于优先级编辑等动作；控制器组件统计是贴图和文字。
- 16 种连接图完整采样 AE2 glass cable 的 center/connection/straight 顶面和 UV。保留原素材透明孔洞，不再画纯色连接臂。12 张核心帧从 controller_lights.png 等距裁取并合成原版底图，保持同为 48×48。供电联网时调用真实 SpriteAnimationHelper.InitSpriteAnimation，每帧 500 ms（原 mcmeta 的 25 tick）；关闭/拆离/停用时移除自有动画，熄灭。复用原生动画管理器，不运行网络扫描、不动态创建纹理；不声称复现原 Minecraft 的插值着色。

当前素材白名单 55 PNG（43 基础 + 12 动画帧），含许可及固定来源哈希。字形刷屏仍按用户要求搁置；没有全局修改字体/日志开关。新命中路径、布局、动画及控件比例都需要用户在真实游戏复测；真实引用编译和元数据检查无法替代现场 UI 验收。

## 0.3.3 原版物品渲染与批量存入

用户报告 0.3.2 终端双击、右键、拖动和外部多选拖入无效。核对本地 Rev6：ItemMouseDoubleClickHandler、ItemContextHandler、ItemMouseDragHandler 用 RaycastElement 查找真实 GameItem/GameItemElement，旧 EmptyPixelElement 投影片无法被识别。仅补拖动按下不覆盖这些入口。原版多选 EndGroupDrag 的普通批量分支调用 GraphUtils.TryAcceptAll → TryFindOneValidInventorySlot → SlotMarker.TryAcceptOnce；旧虚拟槽 numTransfer=0 且提交被统一拒绝，故不会存入。SupportsGroupPlacement=false 仅关闭空间阵列摆放，不是禁用普通批量存入。

方案选择：保留跨容器搜索/分页的非持有目录，借用实际 GameItemElement.handler 的原版渲染树，不再手绘 sprite、数量或命中片；原版双击、右键菜单、提示和拖动识别真实对象，其他模组在这些原版对象上的扩展也可参与。仅改变渲染父级与显示偏移，parentInventory、modifiedShape 和保存图不变。源容器中该实例的同一份渲染会暂时显示在终端中，不支持同时渲染两份；关闭、换页或刷新先按当前真实 parentInventory 归还，移动已重新挂接的渲染不归还旧容器。销毁布局前必须先归还，防止误销毁真实物品。UpdateRectTransform 后只重施自有显示偏移。

不选用“把终端变成普通拥有型库存”：这会实际取走网络容器物品、改变容量与保存语义。逐容器原版库存展示虽简单，但不提供当前统一搜索/排序。选择原版真实渲染加目录布局，并保留网络存取门禁。

外部多选拖到终端空白区域采用原版逐件批量路径；虚拟 SlotMarker 仅表达路由请求，提交时逐件重新读网络、供电、总线权限、容量与来源，并使用既有 NativeMove。绝不把物品放入虚拟库存。部分数量请求拒绝；失败物品留源，未知结果锁定后续移动，不承诺整批原子成功。精确阵列摆放仍不支持；终端内框选跨容器物品也未新增，原版框选依赖真实库存/窗口保存图，不能靠填充虚拟 childItems 伪造。

验证：Windows Rev6 真实引用编译及补丁元数据审计；模型测试仅证明既有模型。真实 UI 尚待用户复测双击开容器、右键菜单、单件拖出、外部多选拖至终端空白、关窗恢复源容器显示，以及容量不足/权限拒绝和保存往返。此次未启动游戏，不声称已验证跨模组运行兼容性。

## 0.3.4 连续滚动与可见区域渲染（2026-11-01）

终端由 GameGridInventory 背景换为原版 GameGridScrollableInventory，复用滚轮、拖动滑块和原生裁剪，去掉页码及翻页按钮。统一目录连续 shelf 排布，搜索、类别与排序改变时回到顶部；库存事件刷新保留当前滚动位置并按新范围收敛。精确目标仍以滚动内容的局部坐标核对，不把屏幕坐标当作库存坐标。

该类原版滚动范围按 childItems 计算；自有子类保持 childItems 为空，GetMinVisibleHeight 补丁只为自有网格提供目录显示高度，不伪造库存物品。保留一行末尾余量，避免原生滚动比例的零分母。物品拖拽和群组拖拽期间冻结滚轮/滑块的内容移动，避免回收正在拖拽的渲染。

开终端或滚动时仅借用视口及下一行范围有实际占格的物品；用占格哈希索引查询该范围，滚动不遍历整网目录，也不重新扫描真实库存。仍可见的 ItemTile 保留，只归还离屏物品并借入新出现的对象。大物品跨视口边界仍可显示，不按来源坐标或旧页号裁掉。离屏物品恢复原容器渲染；关终端前归还全部已借用渲染。

性能边界：滚动显示查询 O(网格宽度×可见行数)，渲染数量受可见占格约束；首次搜索/排序的目录排放和库存变更后的重排仍处理全部匹配物品与占格，写入前仍重新读取真实网络。这是实现成本分析，不是实机帧率或跨模组性能测试。大型界面是否卡顿仍需游戏中验证。

验证：79 项模型测试通过，含千件连续布局、视口边界和超大物品；Rev6 编译 0 警告 / 0 错误，18 项补丁元数据审计 PASS。未运行 Unity，不据此宣称滚动条外观或输入已通过实机验收。用户复测：滚轮和拖动滑块到顶部/底部、搜索后回顶、滚动后双击/右键/拖出、外部多选拖入、关终端后源容器显示恢复。

## 0.3.5 双视图、单一真实物品（2026-11-01）

用户否定借用渲染导致原容器暂时不可见的取舍。本节取代 0.3.3/0.3.4 的借用说明：终端不再移动 GameItemElement.handler，也不移动其 middle/fakeMiddle，不改原容器的任何渲染父级。原容器显示保持原位。

评估：原版 GameItemElement 同时承担真实物品状态和唯一渲染树，不提供直接增加第二套渲染的公开方法。复制 GameItem 或把物品接入终端库存会引入第二份状态或改变保存归属；继续借用会让两个窗口争用同一棵树。因此选择独立的原版 UI 节点镜像：通过 TreeNodeRender 的原版 prefab 工厂复制 middle 的纯视觉节点，包括图片、文字、变换、遮罩、原版叠加精灵；镜像根节点以真实 GameItemElement 作为 element 身份。RaycastElement<GameItem/GameItemElement>、TooltipListener 等原版识别继续返回同一个真实物品。源和终端的物品引用相同，只有 UI 节点各自独立。

没有构造或复制 GameItem，没有克隆源 GameObject、MonoBehaviour 或回调；不把镜像加入 children/childItems 或保存图。关闭、滚出视口和重排只销毁终端自己的镜像节点，不再有“归还源渲染”的步骤。原版拖拽仍用真实物品的原生临时预览，终端起拖时重新定位预览并保持终端窗口在前。实际存取仍走已有来源、网络、权限和未知结果锁定检查。

原版 ValidateSelect、ValidatePartialSprite、ApplyAnimationFrame、HandleModSprite、HandleInnateModSprite 和 RefreshPlayingFrame 完成后，只为有可见镜像的实例排队同步，同一实例同一更新周期合并。节点数量和类型不变时复用节点，结构变化才重建子节点；字形、精灵和材质只读取源组件的公开属性，反射属性信息缓存。库存变更仍由既有事件更新目录。连续滚动、原版滑块和可见区域限制保留，滚动只增减可见镜像。

兼容边界：复用的是原版输入处理及真实对象身份，不承诺复制其他模组附加的任意自定义 Component、直接操纵原渲染的私有回调、非 TreeNodeRender 子树或绕过上述验证入口的自定义动画。此类扩展需要针对性适配；不能把编译通过称为所有模组兼容。终端内部跨容器框选/精确群组阵列仍未新增，外部多选逐件存入路径保留。

验证：79 项模型测试通过；Rev6 真实引用编译 0 警告/0 错误，23 项补丁元数据审计 PASS。静态审查确认镜像代码只对新 UI 节点写入，没有源渲染 reparent、GameItem 构造或库存写入。未启动游戏，双窗口输入和渲染外观仍需用户运行验收：同时打开终端与源容器，两边均显示物品；分别双击/右键/拖动；从任一侧搬运或改变数量后另一侧更新；滚动后操作、外部多选存入、关闭终端后源窗口不变；最后核对保存往返。模型测试和补丁审计不验证这些真实 UI 行为。

## 0.3.6 网络存入整区高亮

用户已确认卷纸不可存入/不可见是其配置问题，停止相关排查，没有修改卷纸、过滤策略或存取规则。仅修订终端单件拖入的反馈：HighlightSlot 和多选使用的 HighlightWholeInventory 均显示整个可见网格，沿用原版绿/红网格素材；不再暗示虚拟终端中存在与拖动预览对应的物理槽位。实际目标仍由释放时的总线优先级、过滤与容量决定，高亮不是放置授权或容量承诺。

高亮节点位于视口本地坐标，处于背景上方、物品下方且不参与射线；数量限定为宽度×可见行数，滚动到深处不为此前所有目录行分配节点。拖出与取消继续由原版 HighlightManager 清理。幽灵筛选格保持原有单槽反馈。

Rev6 编译及 23 项补丁元数据审计通过；未启动游戏，整区高亮的实际外观与清理需用户复测。Core、卷纸数据及总线过滤均未改动，本次不扩大模型测试。

## 0.4.0 筛选网格、数量排序与四面总线升级（2026-11-01）

按用户反馈，筛选区域改为独立 GhostFilterInventory，继承原版 GameGridInventory 并使用机器格子样式；不再复用终端 GameGridScrollableInventory。固定九列，随容量卡由 18 格扩展至最多 63 格（标签模式最多 54 格），一次显示全部格子。拖入仅复制过滤条件，SlotMarker 的普通提交与 UncheckedAccept 继续拒绝，防止物品进入幽灵格。终端保持原版滚动条和独立 UI 镜像。

数量排序改为按当前搜索/类别结果中同 ItemId 的总数量降序，同类型保持相邻，内部按单实例数量降序，完全相同的数量保留原生枚举顺序；移除随机会话 Guid 对相同数量的排序影响。只改变目录顺序，不合并实例或状态。终端背景采用普通 GameGridInventory 的原版 Tan/Grid 材质，替换 GameGridScrollableInventory 默认的 Black/Grid。线缆本身的原版背景 Image 使用 alphaHitTestMinimumThreshold=0，允许整个 1×1 物品格命中，形状仍为原先的一格；独立终端镜像继承该命中设置。

### 四面总线

用户明确选择不兼容旧独立总线，由其手动拆换。因此旧独立总线不再作为主栏中的网络节点，不执行自动迁移或删除；把这些真实总线拖到线缆上即可重新安装，其过滤条件和原来的升级卡子图继续跟随总线物品。

每根线缆拥有一个原生 4×1 子库存，只允许四个真实存储总线实例。安装通过原版拖入容器路径；每个总线在自身 state 中保存本地方向 cable_face（上、右、下、左）。优先选择未装总线且没有传输连接的面；全都已连接时确定性地切断其中一个未装总线面的连接，第四个总线使线缆四面均无外部传输连接。安装面随宿主线缆的旋转/翻转映射到世界坐标，不改总线过滤配置。侧面以现有许可总线纹理的 4×4 区域作为原版 ItemSpriteModifier 标记，不新增 PNG 或纹理像素数据。

拓扑中每个嵌入总线仍是只连接宿主线缆的叶节点，独立消耗 1 频道和每晚 1 kJ；安装面不能桥接相邻线缆或核心。总线朝该面的直接相邻自有容器读取/存入，四个总线各自保留优先级、访问模式、过滤条件及容量/标签卡。整根线缆旋转会使各面共同旋转。双击线缆后选择面打开总线配置；扳手对线缆使用后选择一面卸下，连同总线自己的升级卡完整回到主栏。卸下后可对独立总线使用扳手拆出其升级卡。主栏放不下时原位保留，不拆分或删除。原生交换入口的拆卸锁也覆盖线缆子库存。

### 存档与验证边界

本地 Rev6 的 SaveManager.DecodeNodesInternal 按每个物品自身的非 GameItem 子图重建库存节点表；新增线缆子库存不会重排其他容器或总线的原有子图。旧线缆此前没有保存子物品，新工厂给它建立空的总线槽。加载时保留已保存的 cable_face，不重新选面；已有电池预算/结算逻辑未变。以上为静态契约检查，不等于真实旧存档载入、保存往返或供电回调已验证。

本次 83 项模型测试通过，覆盖四面选择、优先空面、被阻断的面不可传输、四总线孤立线缆不桥接核心、按搜索结果的类型总量排序且不合并实例。Rev6 编译 0 警告/0 错误，23 项补丁元数据审计 PASS。未启动游戏，以下需用户在测试档验收：

- 筛选 18/27/…/63 格完整显示且无滚动条；终端仍可滚动。
- 背景颜色、数量排序和线缆透明边缘双击/拖动命中。
- 总线拖到线缆上、四面独立配置、优先未连接面及切断已有连接。
- 第四总线使整根线缆断开；拿起旋转后，面向容器和阻断方向同步改变。
- 扳手逐面拆卸，容量不足时原位保留；旧独立总线手动重新安装。
- 装有四个总线和升级卡的线缆保存/重载，以及原有容器、过滤和电池结算恢复。

## 0.4.1 直接部位交互与终端框选（2026-11-01）

### 线缆无独立界面

移除线缆统计/面选择窗口及扳手选择弹窗。双击原版输入处理的 mousePosition 转到线缆 rotator 的本地 16×16 坐标，按各安装面的模型投影命中，直接打开该真实总线的配置。线缆旋转/翻转由原版 Transform 反变换处理，本地面配置不变。中心及未安装部位不弹窗，仍允许拾起整根线缆。右键原版 OpenContentAction 对线缆被阻止，避免暴露仅用于保存图的原生四槽窗口。扳手对准哪个总线部位就卸下哪个，卸不下仍原位保留。

使用当前游戏自己的 UnityEngine.InputLegacyModule.dll（Private=false）读取扳手/群组输入位置，加入必需引用检查；不分发该 DLL，也不增加 NuGet 依赖。

### AE2 模型外观

从固定 AE2 storage_bus_base.json 的 up 面及其默认 UV 读取 storage_bus_sides.png，呈现两层薄面板与后部连接柱，去掉旧手绘黄色箭头和 4×4 中央块。总线与线缆中心之间的内部短接头使用已固定 glass_cable_connection 模型的 UV；只绘制内接段，不恢复该面的外部传输连接。四向透明贴图独立叠加，整体只占线缆一格。新增 4 向亮/暗共 8 PNG，白名单总计 63 PNG，许可/来源声明同步更新。

生成器保留二进制素材固定哈希校验；文本模型仅兼容 Git for Windows 的 CRLF/LF 转换。使用已捆绑 Pillow 12.3.0 生成。贴图模型像素与命中区一致性测试通过；离线组合预览已检查，不当作游戏截图或实机外观验收。

### 终端多选框选

原版 ComputeBandItems 沿窗口保存图找物品，并按 GameItemElement.middle 的源容器位置及源库存裁剪判断相交；独立终端镜像不在保存图中，因此原版找不到它们。补丁仅在从终端窗口开始框选时改用当前可见镜像的布局占格，按终端视口裁剪并排除被其他窗口遮挡的区域，返回同一个真实 GameItemElement 给原版选择器。原容器框选枚举保持原生。

选中蓝色格在镜像位置绘制，不把源库存的高亮借到终端。原版保留选择状态、来源跟踪、输入门槛和临时预览；从终端起拖时将群组预览对齐镜像位置，防止从隐藏源容器位置飞入。若从源容器中的同一真实物品起拖，则交回原版处理。释放前按实例走现有 NativeDrop，重新核对网络、供电、策略、来源和完整数量；未知结果锁定后停止后续移动。调用原版 Cancel 清理预览，避免重复提交；不克隆物品，不改保存归属。

框选及选择高亮仅查询可见格，超大物品也不为全部离屏占格分配节点。搜索、库存刷新、滚动离开原视口或关窗时清空原选择；物品拖拽期间继续冻结内容滚动。终端内同目录放下群组不实际搬动物品，不提供精确阵列重排或整批原子性承诺。批量移动后的目录刷新合并一次，避免每件物品再重复重建 UI。写入前的逐项真实复查仍保留。

### 验证

85 项模型/贴图测试通过，包含四向模型命中、未安装面/中心不打开、PNG 像素与命中区一致性和原有拓扑/存取模型。Rev6 编译无警告/错误，29 项只读补丁元数据审计 PASS。框选、窗口坐标、群组预览和实际存取没有在 Unity 中运行；测试不能代替实机验收。

用户复测：旋转/翻转后双击每个总线部位；中心不弹窗；扳手直拆指定部位；终端从空白处拖框并看到蓝色选中，再从选中物品起拖到普通容器；滚动后重新框选；锁定/断网/容量不足保持来源物品；同时开原容器时其原生框选及拖动仍可用；Esc/关窗取消预览不搬物品。
