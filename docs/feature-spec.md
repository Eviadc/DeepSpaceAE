# DeepSpaceAE功能规格

版本0.17.1-alpha，目标100-Rev13 / 0.46D / Steam Build26525552。本文描述当前设计与实现合同，功能用例不代表已执行结果。自动合成尚未实现。

## 物品与网络

| 部件 | 占格 | 连接/容量 |
| --- | --- | --- |
| 核心 | 3×3 | 网络核心，无设备数量上限 |
| 线缆 | 1×1 | 四面总线升级，无频道上限 |
| 存储/输入/输出总线 | 独立1×1 | 安装在线缆上 |
| 无线连接器 | 2×2 | 持久ID成对连接任意物品栏 |
| 放置/吸收总线 | 独立1×1 | 线缆安装；面前一格或整个物品栏 |
| 终端 | 2×2 | 统一访问网络 |
| 硬盘驱动器 | 2×2 | 2至10盘位 |
| 小盘/大盘 | 2×1 | 64/256格 |
| 物品/流体接口 | 2×2 | 流体缓冲20升 |
| 抽屉 | 2×2 | 基础16件，经控制器或存储总线访问 |
| 抽屉控制器 | 2×2 | 四向毗邻抽屉共用入口；直接接入AE并设置优先级 |
| 能源接收器 | 2×2 | 三个电源槽；不提供正常获取 |
| 容量卡/标签卡 | 1×1 | 按宿主规则生效 |
| 扳手 | 1×3 | 配置工具 |

主物品栏、有效拥有的原版机器区／扩建机器区（含各独立页），以及任意有效拥有的无线连接器所在物品栏中的组件按真实占格接触组网；每个物品栏使用独立坐标，非网格物品栏不凭列表顺序推测物理接触。核心、线缆、终端、驱动器、物品接口、流体接口、无线连接器、抽屉控制器和能源接收器均可转发网络，保留各面的合法接触；设备可直接串联或成环，无需绕行线缆。总线只有所属线缆的连接，不经朝向的容器或机器转发。普通容器、抽屉、硬盘和卡片本身不属于传输节点。
每张连通网络只接受一个核心；没有核心则离线，经设备或线缆连接两个核心时整张网络报告核心冲突，移除多余核心后恢复。环路不重复计算设备、库存或耗电，独立设备参与传输时仍保留其功能。0.15.2 及更早版本中被设备隔开的网络，更新后可能连为一体，需保持每张网络只有一个核心。
组件单击保留原生交互，双击打开配置；线缆本身无独立UI。核心灯光及连接贴图由事件刷新。

## 线缆、总线与筛选

将总线拖到线缆上安装；优先未连接空面，无空面时切断一面现有连接。每根最多四条，装满后不能向外连接。整根旋转/翻转时总线随之转动。
双击对应总线部位打开配置。扳手按实际面拆卸并保留设置及卡片；主栏无落点时拒绝。此拆卸交互目前仍有未确认的故障报告。

存储总线识别朝向的真实容器，支持优先级、读写/仅存入/仅取出、包含/排除及提取过滤。重复观察同一容器不重复列物品，允许提取的路径取并集；存入按优先级和稳定顺序选目标。
存储、输入、输出、放置和吸收总线的配置按钮直接显示当前优先级；编辑时同步更新，无需进入编辑窗口查看。
过滤栏为九列幽灵格，基础18格，每容量卡加9格，五个升级位。标签卡最多一张，可按物品有效标签匹配；默认黑名单，空黑名单允许全部；白名单为空时拒绝全部，包括普通、精确、标签及流体匹配。明确保存的模式保持不变。幽灵样品不持有真实物品，超出当前容量的规则保留但停用。过滤栏扩行，不使用滚动条。

## 终端

12×8连续滚动视口、两行工具栏、原版库存背景。名称/ID多词搜索、标签搜索、类别和当前顾客需求筛选均内置，无需标签卡；支持名称和数量排序。
每个终端记忆上次窗口位置；标题栏尺寸按钮沿用原版平板的100%→50%→75%循环。缩放档位由终端共享，位置和尺寸随当前存档保存，缩放和屏幕布局变化时按实际尺寸限制在屏幕内。
终端与源容器可同时显示操作，镜像指向同一真实物品，不改变归属、unitCount或保存图。
相同状态物品合并显示右下角总数；仅在分组比较中忽略进价，真实进价不变。默认且禁用的空标签视为缺失，不忽略其他有效状态。空容器可合并，非空或未知扩展状态独立显示；液体逐来源显示。
单击、双击、右键、工具目标均作用于顶端真实物品；拖动、框选和快捷转移每堆至多一件。按筛选后的堆叠数量排序。滚动或过滤清理旧选择，库存及状态变化自动刷新。
只接收有效拥有的物品。实际写入使用一次当前网络与原生槽检查；接受原生数量结果。批量逐项执行，失败不回滚已成功项。向终端拖入时高亮整个接收区。

## 硬盘与抽屉

驱动器是2列×5行真实盘位，只收本模组硬盘；初始两个，每容量卡解锁两个，最多四卡。拆卡须清空将关闭的末行。卡片不进入网络目录。
驱动器可设置正数、零或负数优先级，并在面板直接显示。与存储总线共同参与存入路由，优先级较高的可用目标先接收，同一驱动器内仍按盘位顺序选择。
硬盘按真实物品modifiedShape的占用格数计容，不考虑形状摆放；原生堆叠按其占格计，不乘数量。单件不跨盘分割，按盘位顺序选择有空间的盘。盘及驱动器不能递归存盘，取盘保留真实内容。超容时允许提取而不丢弃物品。
抽屉只收一种相同状态物品，基础16件，最多五张容量卡，每张×4，上限16384件。进价不影响同种判断，各实例状态保留。拆卡导致超容时拒绝。锁定会记住当前物品种类，取空后仍保留该种类及图标；空抽屉可预先锁定，绑定下一件放入的物品。解锁并清空后才能换种类，已有库存仍执行同状态准入。锁定状态和种类随抽屉保存；本地操作免电，经总线访问遵守网络规则。
抽屉提供默认关闭的“溢出销毁”选项。开启后只销毁新投入的、符合类型及状态规则而超出容量的部分；原库存、加载的超容库存不会因此销毁。模式随抽屉保存，关闭后恢复正常满容量拒收。

## 液体与接口

接口及存储/输入/输出总线通过原生右键Toggle或配置按钮切换物品/流体形态，保留实例ID、真实存储图、升级卡及筛选配置；接口液体未空时拒绝切回物品。新获取不再单独提供流体接口；旧工厂标识保留供存档读取。
流体形态的存储总线朝向液体容器时读取真实WaterHelper成分；不同成分不合并，同配方也保留来源、温度与过滤状态。
终端液体卡复用原生选中/Target交互，主动混液、过滤和滴管反向沿用原版；卡片不搬走源罐，不手写成分标签。
物品接口是进入网络的非拥有落点，不储存副本；要求有效拥有并使用真实目标SlotMarker。
流体接口提供20升原生缓冲。输入模式严格匹配时只向相同成分或空容器送液；关闭时允许原生混液。输出模式选取一种精确配方补液。流体转移有界、事件驱动，仅使用原生TransferLiquid。

## 机器自动化

方向按AE2：输入总线从机器output槽或普通储物区收回网络；输出总线把网络物品送至input槽或普通储物区。普通容器和明确标为storage的区域均可使用，多页容器包含未选中的页；不递归搬取嵌套容器内部物品，不把机器电池／升级槽或抽屉升级位当作普通库存。新产出优先路由仅针对机器output槽，不截走普通存入操作。
只识别真实MachineryPanel.role及直属库存，排除NO_HOPPER、电池、模块、芯片和便签槽；未知机器明确拒绝，不猜槽位。
默认模糊物品ID匹配，可切换精确幽灵状态；精确模式仍比较进价。标签升级按有效标签筛选。
朝向机器输出槽的已启用物品输入总线会优先接收刚生成的产出，再由原版输出槽、料斗溢出和主库存处理余量；离线、拒收或网络满时完整保留原版后备路径。此路径使用相同总线筛选、网络优先级和原生准入，不搬动已经放入其他库存的物品。
定时收取已有产物仍在原生料斗窗口之后运行，每总线最多8次、全批最多64次；每批共享网络观测，实际移动使用原生准入。夜间使用同日已结算预算，不二次扣电。

## 无线与面板总线

无线采用 AE2 Stuff 的成对网络连接概念及原生料斗的选中/Target交互。双方保存对端持久ID；重新配对先解除原配对，只有互相指向且有效拥有的两端才生成网络边。物品栏窗口无需打开。无线边参与普通连通图，因此双核心冲突、环路去重及实验耗电规则一致。主物品栏、原版机器区／扩建机器区及包含有效连接器的库存启用物理组网，普通库存里的备用设备不自动启用。

放置/吸收总线只处理物品，基础筛选、升级、黑白名单及精确匹配规则与输入/输出总线一致。默认只处理线缆旋转/翻转后总线朝向的一格；该格占用时不放置，也不合堆。空白名单不放置，空黑名单允许所有合格物品。全空间模式处理所在物品栏的直属物品，不递归；吸收排除全部 deepspaceae 组件及原生料斗，也拒绝移动包含本总线的祖先容器。所有移动使用原生 SlotMarker、容量、锁和所有权检查。每条总线最多8次、单批64次；面板每次成功移动后重新解析网络和权限。

流体输入/输出总线作用于面前真实液体容器，或机器对应 output/input 槽中的液体容器。遵守网络液体存储总线的优先级及读写筛选，使用原生 TransferLiquid；不移动瓶罐。默认严格成分相同或空罐，可配置允许混液。流体输入/输出总线的幽灵样品采集实际液体：模糊匹配组分种类，精确匹配比例，忽略瓶型、液量与温度；标签卡仍使用容器的原生标签。

## 获取与商人

王尔德的AE工程师升级费用200，赠送基础18件组件及6322电话条。网络工程师开局保留普通物资、标准储藏区、23件AE组件和电话条，并将王尔德礼包记为已领取。两种礼包均包含两个无线连接器，不赠送电池；接口不在礼包中。开局简介采用简短职业背景，物资与解锁项单独列出。
每次领取固定该次礼包清单，按原生接收结果推进游标；主栏满或拒收时保留待发实例，不销毁或重复生成。更新不会重放已经发完的礼包；旧的未发完礼包只继续尚欠物品，不再发电池。
福鲁伊克斯研究员只接受电话预约，无自然出现。拨打6322预约次日，重复拨打不延期、不重抽货单；到期开门后进入原生来访队列，实际接待后清预约。
无线连接器每次必定供货，每次为2个或4个，成对优先上架；货台只剩单个空位时撤回未成对的供货。旧预约货单中的落单连接器不单独上架。其余硬盘固定份额为小盘2个、大盘1个（价格200/800）；另外小盘75%概率追加1–3个，大盘15%概率追加1个。线缆3–6根；容量卡必出3–5张，标签卡固定1张，25%概率追加1–2张。核心、驱动器、终端、接口及扳手每批最多1个，抽屉及面板总线1–2个，存储总线2–4个，输入／输出总线1–3个。其他品类按AcquisitionCatalog抽取，不补齐货台、不在购买后补货。
见面及交易使用村民哼声，电话附简短日期解释。原生不保存的当前NPC/未购货台不由模组恢复。

## 默认免电与实验耗电

默认不预留、不锁电池、不扣电、不增加AE电费；拓扑、权限和原生锁仍有效。
开启模组设置中的测试耗电选项后，按整网当日最大成本作为预算，移除设备不降低已记录峰值。核心2kJ，线缆0kJ，总线、终端、驱动器及接口各1kJ，能源接收器0kJ。
核心与在线接收器共用电源，选数量最少且足够的组合，等数量优先保留既有组合。只锁必要电池；不足则当天断网、释放失败及未执行份额，可用足够的新电源恢复。未结算峰值不跨日。
普通电池睡眠结算，以原生DrawPowerSource的bool为准；保留成功记录，不重复扣电。电流转换器遵守原生电网服务，欠费次日锁槽断电，实际付款事件结算费用。
关闭耗电清理已知未扣预留，已成功或中断未知账目不退款、不重放。能源接收器不在商人或拾荒获取列表中。

## 修改时间排序

终端排序新增“修改时间”，最近变化的物品堆在前。同种完整状态采用与终端相同的堆键（继续忽略进价），由网络记录总数量与修改时间；记录属于核心标识的网络，保存在当前世界ModData，不添加物品标签。存入、取出、数量变化及状态分组变化更新记录；有内容的容器仍独立显示，直属库存变化也更新该条目。

同一网络内移位但总量和状态不变不刷新时间；切换筛选、开关终端和保存重载不刷新时间。新引入该功能时已有库存作为无先后顺序的初始基线。断开的容器不继续跟踪，重新接入时以该网络的新库存变化记录；临时移走整个核心不清掉已保存记录。各网络独立，多个终端共享同一记录；液体保留各来源并按其内容变化排序。

## 成交自动收纳

物品接口新增“自动收纳购入物品”，默认关闭并保存于接口配置。开启且在线后，单件成交及批发购买完成付款、归属和进价设置后，商品直接存入该接口所在网络。沿用总线优先级、筛选、容量、原生移除与接受规则以及可选供电规则，保留真实实例与进价。

多个已开启接口按稳定设备标识尝试，同一网络只尝试一次。部分收纳后原版处理余量；断网、无电、拒收或满容量时采用原版落点，不吞物品、不排队补收。开关不会收走购买前的库存，也不会收取尚未付款的商品。

## 保存与验证

真实原生库存和状态保存物品及配置；镜像、缓存和幽灵筛选不复制物品。Alpha版本以新建存档为开发基线，不提供历史存档迁移。
游戏版本更新需重新核验绑定与关键[功能用例](functional-cases.md)；编译或静态审计不能代替实际游戏验收。

## 0.17 抽屉控制器与操作规则

控制器仅在同一实际网格库存中沿自有抽屉的上下左右接触收集库存；对角、空隙、非抽屉物品和其他物品栏均不连接。普通抽屉不加入 AE 拓扑，不能借抽屉链为另一端的控制器传输 AE。控制器本地取放不要求核心；接入有效 AE 后，以面板的正负优先级与驱动器、存储总线共同路由。优先尝试已有内容或已锁种类的抽屉，再尝试空抽屉。多条路径不重复计入目录。

点击抽屉主体并使用游戏的快捷转移修饰键，转移顶部真实库存至该键绑定的主物品栏、柜台或后备仓库；不会搬走抽屉本身。容量、所有权和原生移除锁继续有效。
手动“立即运行”不设每总线8次、全批64次的上限；基于有限候选快照和每次原生槽检查，移动至源耗尽、目标满或准入拒绝。夜间自动运行仍保持原预算。手动物品放置／吸收不反复扫描已处理候选；普通物品移动不重建 AE 拓扑，移动容器或组件时重新核验。
激活的 AE 组件在原生固定状态上叠加自动固定；失活、断开、卸载或切换存档时解除自动部分，不覆盖原生手动固定标签。
村民连接器供货概率为100%，每次2或4个，货台只放完整的一对；拾荒表内连接器权重从1提高到4。
