# DeepSpaceAE功能规格

版本0.14.0-alpha，目标100-Rev6 / 0.46D / Steam Build26337366。本文描述当前设计与实现合同，功能用例不代表已执行结果。自动合成尚未实现。

## 物品与网络

| 部件 | 占格 | 频道/容量 |
| --- | --- | --- |
| 核心 | 3×3 | 提供32频道 |
| 线缆 | 1×1 | 每段最多8频道，四面总线升级 |
| 存储/输入/输出总线 | 独立1×1 | 安装后各1频道 |
| 终端 | 2×2 | 1频道 |
| 硬盘驱动器 | 2×2 | 1频道，2至10盘位 |
| 小盘/大盘 | 2×1 | 64/256格 |
| 物品/流体接口 | 2×2 | 各1频道，流体缓冲20升 |
| 抽屉 | 2×2 | 基础16件，经存储总线接网 |
| 能源接收器 | 2×2 | 1频道，三个电源槽；不提供正常获取 |
| 容量卡/标签卡 | 1×1 | 按宿主规则生效 |
| 扳手 | 1×3 | 配置工具 |

直接位于已拥有屏幕主栏中的组件按真实占格接触组网。一个传输分量只接受一个核心；多核心冲突、跨独立分量接触或频道不足可使设备离线。叶子设备不桥接独立网络。
组件单击保留原生交互，双击打开配置；线缆本身无独立UI。核心灯光及连接贴图由事件刷新。

## 线缆、总线与筛选

将总线拖到线缆上安装；优先未连接空面，无空面时切断一面现有连接。每根最多四条，装满后不能向外连接。整根旋转/翻转时总线随之转动。
双击对应总线部位打开配置。扳手按实际面拆卸并保留设置及卡片；主栏无落点时拒绝。此拆卸交互目前仍有未确认的故障报告。

存储总线识别朝向的真实容器，支持优先级、读写/仅存入/仅取出、包含/排除及提取过滤。重复观察同一容器不重复列物品，允许提取的路径取并集；存入按优先级和稳定顺序选目标。
过滤栏为九列幽灵格，基础18格，每容量卡加9格，五个升级位。标签卡最多一张，可按物品有效标签匹配；空规则匹配全部。幽灵样品不持有真实物品，超出当前容量的规则保留但停用。过滤栏扩行，不使用滚动条。

## 终端

12×8连续滚动视口、两行工具栏、原版库存背景。名称/ID多词搜索、标签搜索、类别和当前顾客需求筛选均内置，无需标签卡；支持名称和数量排序。
终端与源容器可同时显示操作，镜像指向同一真实物品，不改变归属、unitCount或保存图。
相同状态物品合并显示右下角总数；仅在分组比较中忽略进价，真实进价不变。默认且禁用的空标签视为缺失，不忽略其他有效状态。空容器可合并，非空或未知扩展状态独立显示；液体逐来源显示。
单击、双击、右键、工具目标均作用于顶端真实物品；拖动、框选和快捷转移每堆至多一件。按筛选后的堆叠数量排序。滚动或过滤清理旧选择，库存及状态变化自动刷新。
只接收有效拥有的物品。实际写入使用一次当前网络与原生槽检查；接受原生数量结果。批量逐项执行，失败不回滚已成功项。向终端拖入时高亮整个接收区。

## 硬盘与抽屉

驱动器是2列×5行真实盘位，只收本模组硬盘；初始两个，每容量卡解锁两个，最多四卡。拆卡须清空将关闭的末行。卡片不进入网络目录。
硬盘按真实物品modifiedShape的占用格数计容，不考虑形状摆放；原生堆叠按其占格计，不乘数量。单件不跨盘分割，按盘位顺序选择有空间的盘。盘及驱动器不能递归存盘，取盘保留真实内容。超容时允许提取而不丢弃物品。
抽屉只收一种相同状态物品，基础16件，最多五张容量卡，每张×4，上限16384件。进价不影响同种判断，各实例状态保留。拆卡导致超容时拒绝。清空后可换种，面板和物品表面显示代表图与总数；本地操作免电，经总线访问遵守网络规则。

## 液体与接口

存储总线朝向液体容器时读取真实WaterHelper成分；不同成分不合并，同配方也保留来源、温度与过滤状态。
终端液体卡复用原生选中/Target交互，主动混液、过滤和滴管反向沿用原版；卡片不搬走源罐，不手写成分标签。
物品接口是进入网络的非拥有落点，不储存副本；要求有效拥有并使用真实目标SlotMarker。
流体接口提供20升原生缓冲。输入模式严格匹配时只向相同成分或空容器送液；关闭时允许原生混液。输出模式选取一种精确配方补液。流体转移有界、事件驱动，仅使用原生TransferLiquid。

## 机器自动化

方向按AE2：输入总线从机器output槽收回网络；输出总线把网络物品送至input槽。
只识别真实MachineryPanel.role及直属库存，排除NO_HOPPER、电池、模块、芯片和便签槽；未知机器明确拒绝，不猜槽位。
默认模糊物品ID匹配，可切换精确幽灵状态；精确模式仍比较进价。标签升级按有效标签筛选。
原生料斗窗口之后运行，每总线最多8次、全批最多64次；每批共享网络观测，实际移动使用原生准入。夜间使用同日已结算预算，不二次扣电。

## 获取与商人

王尔德的AE工程师升级费用200，赠送基础16件组件及6322电话条。网络工程师开局保留普通物资，额外标准储藏区、21件AE组件、满电电池和电话条，并将王尔德礼包记为已领取。接口不在礼包中。
礼包按原生接收结果推进游标；主栏满或拒收时保留待发实例，不销毁或重复生成。
福鲁伊克斯研究员只接受电话预约，无自然出现。拨打6322预约次日，重复拨打不延期、不重抽货单；到期开门后进入原生来访队列，实际接待后清预约。
供货固定包含1个大盘（价格800），最先摆放，避免被其他商品占满货台。线缆6–10根，不用于补齐货台；容量卡必出、基础6–10张，标签卡25%概率、基础2–3张。其他品类及补位以AcquisitionCatalog为准，不在购买后自动补货。已预约的货单保持原样，新规则从更新后新预约的货单生效。
见面及交易使用村民哼声，电话附简短日期解释。原生不保存的当前NPC/未购货台不由模组恢复。

## 默认免电与实验耗电

默认不预留、不锁电池、不扣电、不增加AE电费；拓扑、频道、权限和原生锁仍有效。
开启模组设置中的测试耗电选项后，按整网当日最大成本作为预算，移除设备不降低已记录峰值。核心2kJ，线缆0kJ，总线、终端、驱动器及接口各1kJ，能源接收器0kJ。
核心与在线接收器共用电源，选数量最少且足够的组合，等数量优先保留既有组合。只锁必要电池；不足则当天断网、释放失败及未执行份额，可用足够的新电源恢复。未结算峰值不跨日。
普通电池睡眠结算，以原生DrawPowerSource的bool为准；保留成功记录，不重复扣电。电流转换器遵守原生电网服务，欠费次日锁槽断电，实际付款事件结算费用。
关闭耗电清理已知未扣预留，已成功或中断未知账目不退款、不重放。能源接收器不在商人或拾荒获取列表中。

## 保存与验证

真实原生库存和状态保存物品及配置；镜像、缓存和幽灵筛选不复制物品。Alpha版本以新建存档为开发基线，不提供历史存档迁移。
游戏版本更新需重新核验绑定与关键[功能用例](functional-cases.md)；编译或静态审计不能代替实际游戏验收。
