# 抽屉与标签筛选

抽屉占2×2，基础16件，五张容量卡逐张×4，容量依次16/64/256/1024/4096/16384。
库存保留每件真实物品，只收同一种完整状态；分组例外与终端一致：忽略进价及默认禁用空标签，不抹除实际标签。ItemCondition按字段值比较。
拆卡会超容时拒绝；清空可换种。卡片不对网络暴露。双击本地抽屉与终端可同时操作，面图像和右下角总数随库存事件更新。

终端筛选内置，不需标签卡。三种总线安装标签卡后使用与实际路由一致的有效标签列表；原始标签键不送入类别翻译器。
装卸卡立即更新标题，空规则匹配全部；包含/排除、提取过滤及优先级继续适用。

控制器使用同栏四向相邻抽屉的连通分量，本地独立可用，接AE后按其优先级暴露库存。普通抽屉不传网；所有权、容量、锁定和溢出规则在真实抽屉上执行。抽屉主体支持原生三类快捷转移键，转移顶部真实库存而非容器。
