# 0.10 抽屉、终端筛选与组件素材

## 抽屉

`deepspaceae.drawer` 是2×2原生容器，不占网络频道、不耗电；用存储总线朝向抽屉接入AE。0.10.1起双击抽屉打开独立原生面板，与终端可同时显示和操作。本地以一个真实代表物品及总件数显示同种堆叠；只有原生数据库存的渲染进入此面板，终端继续使用独立镜像，不借用该代表物品。本地操作只允许归属玩家且位于主库存的抽屉，不需要AE供电；网络操作仍重新核验原网络、总线权限及供电。终端保留滚动条。

基础容量为**16件**，按 `unitCount` 计数而非面积或实例数。五个真实容量卡位置，每张×4：16、64、256、1024、4096、16384。只接收同一种且状态相同的物品；真实实例、数量及状态保存在原生库存中，不改计数伪造库存、不复制GameItem。达到上限拒收，原物留源；现有写入沿用整件/整堆预检，不自动部分塞入超额堆栈。拆下卡会超出新上限时拒绝拆卡。原生交换不能绕过这些检查。

相同判定包含标识、名称/描述、原生价格字段、自定义文字、贴图、类别、完整原始和有效TagState（包括各类型数值及启用状态）、物品特征及本地形状。摆放坐标、朝向、实例ID与数量不作为种类判据。具有真实子库存的物品不入抽屉，避免忽略嵌套内容；未知派生ItemFeature不猜相同。物品在库存中发生状态变化不会被销毁或被改写为同种，新存入须重新核验。清空后下一件决定新种类，不永久锁种。

保存图固定先数据、后升级库存。网络只暴露数据库存，升级卡不成为抽屉商品；加载保留超容量/异种的既有真实物品，进一步插入按当前规则拒绝。未增加旧核心、旧总线或驱动器的保存图节点。

史蒂夫出售抽屉：初始价格160，货单独立概率65%，数量1–2；拾荒表权重2。基础AE工程师礼包不变。

## 终端标签升级

终端新增一个真实单卡槽，只接受标签筛选升级。空槽时保留公开物品类别筛选；装卡后筛选列表提供所有已联网、当前可读物品的有效标签（与总线相同，排除模组内部状态键），并增加“当前顾客需求”。`#标签`搜索同样在装卡后包含完整标签。未枚举全物品目录。

顾客匹配调用当前 `StoreClientInstance.GetClientBlueprint()` 及原版 `StoreClient.IsClientBuyingThisItem`，包含原版拒收、黑名单和内容规则。没有顾客、顾客不收购或交易已完成时结果为空。筛选先于数量排序汇总，不把不匹配的同ID物品计入排序数量。过滤只改显示，不自动出售或搬动物品；移除卡恢复类别筛选并清除不再有效的选择。

窗口存在时每0.25秒只比较一次当前顾客引用，变化后更新显示；不每帧扫描库存或网络。原有真实库存事件和拖动期间dirty保留机制继续适用。

原终端没有真实子库存，此次给终端追加独立单卡子图；旧核心/总线等子图不重排。已有存档升级及新槽保存后重载需要专门验收，不能只依据构建成功宣称完成。

## 素材

驱动器使用AE2 drive front/inside，能源接收器使用energy acceptor，硬盘使用item cell housing、1k/4k层及LED层，无变形地居中放在1×2透明画布中。AE2外观不改变本模组64/256格容量及六个功能盘位。输入/输出总线使用各自AE2原始模型/贴图；安装到线缆时共用原有薄型AE2挂载几何，保持四面命中区域。

抽屉取自Storage Drawers的单抽屉橡木正面，按最近邻放大到32×32。固定提交、逐文件来源和完整许可随源码/安装包保留。白名单共91 PNG：89张AE2原图或衍生图、1张Storage Drawers衍生图、1张独立史蒂夫头像。AE2的CC BY-NC-SA 3.0与抽屉的MIT分别声明。

Core容量及既有回归测试122项；真实Rev6引用构建、补丁元数据审计和运行时结果分别记录，不能互相替代。精简插件新增两项，整体10项：PILOT-08检查16件上限、状态区分、×4卡、拆卡锁定、本地取放、放空改种及真实总线可见性；PILOT-09检查终端单卡门槛、真实标签、原版顾客接受/拒绝及卸卡回退；PILOT-10保存独立新槽。鼠标命中、视觉布局、NPC实交易及保存后重载仍需单独验收。
