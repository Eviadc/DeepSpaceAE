# 0.11 网络工程师开局

新游戏开局列表增加“网络工程师”（`deepspaceae.network_engineer`）。使用原版 `ModHelper.AddStartingScenario`，名称、描述、初始物资摘要通过官方双语本地化提供；不改原版开局枚举，不增加Harmony补丁或贴图。

## 初始资源

- 与当前Rev6普通开局一致的启动开销50；一件破旧存储区、加工肉×2、加工果汁×1、牙膏×2、卷纸×2。跳过序章时还包括原版食品/日用品标牌各一。
- AE基础套件16件：核心×1、线缆×8、存储总线×2、终端×1、硬盘驱动器×1、小硬盘×2、扳手×1。
- 一块原版 `energy_credit` 电池，按其真实最大能量字段充满。未安装到核心前可自由移动，接入后的供电/锁定/跨日规则与普通电池一致。

王尔德的AE工程师升级标记为已领取，不再额外支付200或领取第二套礼包。史蒂夫、普通开局和正常购买AE工程师礼包的规则保留。

原生MODDED场景保留游戏基础店铺、人物特性和序章流程；普通开局特有的上述物资和50开销由适配器按已核验的Rev6分支添加，不通过临时改变startType重跑初始化。

## 发放与保存

场景onStart早于OnNewGameStarted。前者只记权益、序章标记及一次性普通开局开销；会话/主库存就绪且升级注册后，才沿用真实主库存发放队列。仅核验整件或整堆空槽后写入，保留各件真实实例；原生自动找槽偏向已有堆叠时，改以原生TryInventorySlot寻找空位，不将未知堆叠结果视作已交付。

主库存放不下时保留权益，整理空间后开卷帘门或次日继续。发放前记in-flight，确认实际归属后推进游标；未知结果锁定且不自动重发。只销毁从未开始交付的全新候选，不删除真实玩家物品。读档注册升级并恢复已领取状态，不重建发放游标；场景回调重复触发也不再次扣启动开销。

`engineer_start_v1` / `engineer_skip_intro_v1` 与既有gift游标保存在原生ModData；有序v1清单不可直接增删重排。当前25次工厂实例发放，跳序章时27次；每次按真实unitCount完整写入。原普通升级仍固定为16件AE套件。将来改初始平衡值应新增清单版本并明确处理未完成/未知交付。

## 验证范围

构建绑定当前100-Rev6 / Build26337366，固定SDK及依赖不变。原版普通开局分支、StartingScenario注册/持久ID、NetworkUpgrade直接state=2和PowerHelper电量字段均来自本机真实程序集核验。Core有独立清单回归，既有未知交付模型测试继续适用。

专用运行模式：`scripts/runtime-pilot.ps1 -EngineerStart -Launch`，只在新独立槽执行START-01到05，不执行原十项组件夹具。核对原生可见开局、基础套件与电池、重复回调不重发/不重扣、真实核心供电，以及原生保存。此模式跳过序章，不模拟开局选择鼠标点击；保存不等于重新读档通过。运行结果另记，不能将构建通过写成实机通过。
