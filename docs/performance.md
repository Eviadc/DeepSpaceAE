# 性能边界

网络刷新由库存、位置、配置和生命周期事件合并触发，不逐帧扫描全网。主栏及无线连接器所在库存分别建立一次占格哈希索引，连接器候选复用原生FindAllItem的可访问物品树，不进行组件两两比较。
拓扑按传输分量共享一次遍历，包含可转发的独立设备，避免逐设备重复全图BFS；环路通过已访问集合去重，路径共享前缀，不随设备串联长度分配平方数量的路径元素。没有核心或线缆频道上限。
目录只遍历联网可访问容器，重复总线不重复扫描同一来源；同种状态用字典分组，不逐对比较。终端只创建可见区域镜像。
普通机器自动化每批共享一次网络观测；自动总线每总线8次、全批64次，流体接口同样有界。手动运行使用有限候选快照，不设8/64上限；每次检查原生槽，容器或组件移动才重新观测拓扑，普通物品移动不重建网络。实际写入保留必要的当前权限和原生槽检查，缓存不能授予操作权限。
动画复用原版SpriteAnimationHelper，只在帧变化时换精灵；不为动画分配纹理或扫描网络。停用/离线取消登记，关闭窗口解除界面订阅；网络修改记录的库存订阅独立于窗口，随拓扑更新、卸载或切换存档解除。

占格观测成本随物品及占格数增长，拓扑遍历随节点/边数增长，目录分组随真实实例及其状态大小增长。原生库存回调和Unity渲染另计，不能据Core模型测量推断游戏帧率。
可选模型基准入口：`bash scripts/demo.sh --benchmark`；模型结果与实机表现分别记录。

物品堆修改记录只重建发生事件的库存摘要，再按网络汇总同堆数量；显示分组保留完整键，保存记录用SHA-256键摘要压缩体积。只在数量/状态发生变化时写入本网络ModData，不给物品添加时间标签。购入自动收纳只读取路由与目标库存，不为每件购入商品重建终端目录。

抽屉用库存事件及数量验证增量维护总数，普通准入仅比较代表物品；代表状态改变才重查同类不变量。原生库存布局仅验证可见代表，隐藏实例仍保留真实状态与保存身份。快捷取物无需创建网络目录。控制器复用占格哈希查四向邻接，并在同次网络观测内复用抽屉连通分量；不按库存数量重复寻找邻接。

一次同步自动化批次对已满的普通原生网格缓存“没有空格”的否定结果，仍逐物品检查堆叠和特殊转送；增删、数量或形状验证立即失效。该缓存不授权任何写入，避免目标满后为数千件剩余库存重复扫描全部落点。
