# 性能边界

网络刷新由库存、位置、配置和生命周期事件合并触发，不逐帧扫描全网。真实主栏一次占格观测建立哈希索引，不进行组件两两比较。
拓扑按传输分量共享一次遍历，避免逐设备重复全图BFS；没有核心或线缆频道上限。
目录只遍历联网可访问容器，重复总线不重复扫描同一来源；同种状态用字典分组，不逐对比较。终端只创建可见区域镜像。
自动化每批共享一次网络观测，每总线8次、全批64次；流体接口同样有界。实际写入保留必要的当前权限和原生槽检查，缓存不能授予操作权限。
动画复用原版SpriteAnimationHelper，只在帧变化时换精灵；不为动画分配纹理或扫描网络。停用/离线取消登记，关闭窗口解除界面订阅；网络修改记录的库存订阅独立于窗口，随拓扑更新、卸载或切换存档解除。

占格观测成本随物品及占格数增长，拓扑遍历随节点/边数增长，目录分组随真实实例及其状态大小增长。原生库存回调和Unity渲染另计，不能据Core模型测量推断游戏帧率。
可选模型基准入口：`bash scripts/demo.sh --benchmark`；模型结果与实机表现分别记录。

物品堆修改记录只重建发生事件的库存摘要，再按网络汇总同堆数量；显示分组保留完整键，保存记录用SHA-256键摘要压缩体积。只在数量/状态发生变化时写入本网络ModData，不给物品添加时间标签。购入自动收纳只读取路由与目标库存，不为每件购入商品重建终端目录。
