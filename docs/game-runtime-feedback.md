## 已定位并修改的源码

- **主库存绑定错误是本轮根因。** 原包生成、F9 选终端、网络读取及取放目标均使用 `PlayerStore.GetStoreInventory()`。真实程序集显示它只返回 PlayerStore 构造时另建的 `gridInv`；屏幕主库存则由 EmporiumEntry 单独创建的 `invElement` 构成，挂到 `invWindow` 并注册 MainInvArea 增删回调。两者不是同一实例。这解释了不可见的套件生成、手动物品不被认可、F9 读取到与可见库存不符的多个总线/核心。现统一通过 `GameSession.MainInventory()` 使用 `EmporiumEntry.Instance.invElement`；旧库存仅在显式只读诊断中比较，不迁移或自动销毁其物品。修订后仍须真实游戏复测。
- `GameGridInventory.childItems` 返回其直接 `items` 的列表副本，不是递归枚举；未把嵌套枚举当成这次七条总线的根因，也未通过去重或改数字掩盖错误。
- 打开终端时捕获的错误原先写入共享 `message`，之后成功打开仍显示旧错误。改为独立错误窗口及完整异常日志，保留搬运警告/写入锁定信息。
- 生成按钮增加调用编号、生成前后主库存四类计数、直接/嵌套/未保留数量及结果窗口，并请求原生库存状态 UI 刷新；改正根库存后保留原生放置策略。原生 `UncheckedAccept` 本身也请求 UI 刷新，因此没有将“漏刷新”宣称为这次生成无可见结果的根因。
- 终端增加部件计数、实际写入许可、多核心冲突提示及各总线相对于本终端的可访问状态。
- 新增按需只读诊断按钮，展示有效拥有、原生相邻和直接库存观测；不添加每帧扫描、自动清理重复部件、存档修改或新搬运行为。
- 本模组的 ModLog 使用单独 ASCII 显示名称，异常与中文消息转义后写入控制台；原始中文仍可在模组 UI 中显示。不修改实际模组清单、不修补全局字体或隐藏警告。游戏及其他模组的中文日志仍可能触发相同字体问题。
- 增加频道开启/关闭两种模型回归：终端多核心冲突时，即使另一独立网络的总线在线，也不能读取其物品；关闭频道不解除核心冲突。
